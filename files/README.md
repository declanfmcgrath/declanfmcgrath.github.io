This folder holds the PDFs the site links to.

To add one: open this folder on github.com, click **Add file → Upload files**,
drag the PDF in, and press **Commit changes**. Expected names:

- `cv.pdf` — your CV (linked from the CV page once you uncomment its line)
- `msc-thesis.pdf` — your thesis (linked from the Notes page once you
  uncomment its line)
- anything else — link it from an entry with `files/whatever.pdf`
